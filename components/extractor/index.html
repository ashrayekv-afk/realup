Local browser processing

Local privacy boundary

  1. Choose the original Continuum ZIP on the Northwestern laptop.
  2. The browser reads the images locally and extracts the six model values for OD and OS.
  3. You verify and edit every value.
  4. The tool imports only the age, eye, six measurements and, for two scans, the interval in days. Names, MRNs, exact dates, filenames and images are excluded.
  5. Only confirmed numeric inputs go to the model server. Source map images are displayed locally in the bottom viewer.
ZIP reading and OCR run in this browser. This application sends verified numeric values to the model server; it does not send the ZIP or source images. OCR libraries and language data load from external hosts.

Technical and privacy details
  • The page is a static HTML/JavaScript application and contains no form submission or patient-file upload code.
  • JSZip opens the archive in browser memory.
  • Tesseract.js performs OCR through WebAssembly in the browser.
  • The English recognition model is bundled with this app. It loads locally from the app on first use and is normally cached.
  • Exact dates are used locally only to calculate visit order and scan interval. Exact dates are not exported.
  • Click Next patient / clear after the case is complete to remove the selected files and temporary source-page previews from the component.
